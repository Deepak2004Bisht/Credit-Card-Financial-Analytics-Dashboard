<h1>💳 Credit Card Financial Analytics Dashboard (Power BI + SQL)</h1>
An interactive financial analytics dashboard built using <b>Microsoft Power BI</b> and <b>SQL</b> to analyze credit card transactions, revenue, customer demographics, spending behavior, interest income, and financial performance. The project transforms raw financial data into meaningful visual insights to support data-driven decision-making.

<h2>📌 Project Overview / Purpose</h2>

The Credit Card Financial Analytics Dashboard is a comprehensive Power BI project connected to a SQL database. It provides an overview of credit card transaction performance and customer financial behavior through interactive reports, key performance indicators (KPIs), charts, tables, and slicers.

The dashboard focuses on understanding revenue generation, transaction activity, customer income, spending patterns, card categories, payment channels, customer demographics, and quarterly financial trends.

The project contains two main analytical pages:

1. <h3>Credit Card Transaction Report</h3> – Analyzes transaction revenue, interest earned, annual fees, payment channels, card categories, and spending patterns.

2. <h3>Credit Card Customer Report</h3> – Analyzes customer income, demographics, job roles, education, age groups, gender, and customer satisfaction.

<h2>🛠 Tech Stack</h2>
The dashboard was developed using the following tools and technologies:
<br>
<br>
• 📊 Microsoft Power BI Desktop – Used to create interactive reports, KPIs, charts, tables, and dashboard layouts. <br>
• 🗄️ SQL – Used as the database connection for accessing and analyzing financial data. <br>
• 🔄 Power Query – Used for data preparation, transformation, and cleaning where required. <br>
• 🧠 DAX (Data Analysis Expressions) – Used for calculated measures, financial KPIs, aggregations, and analytical calculations. <br>
• 🧩 Data Modeling – Used to organize financial data and support relationships, filtering, and cross-analysis. <br>
• 📈 Data Visualization – Used to present financial trends, customer segmentation, and transaction insights. <br>
• 📁 File Formats – .pbix for the Power BI development file and .png for dashboard preview screenshots. <br>
<br>

<h2>✨ Features & Dashboard Highlights
🔍 Business Problem </h2>

Organizations often struggle to understand:Financial institutions generate large volumes of credit card transaction and customer data. However, raw data alone makes it difficult to understand revenue performance, customer spending habits, transaction activity, and customer financial characteristics.

Important business questions include:

• How much revenue is generated from credit card transactions? <br>
• Which card category contributes the most revenue? <br>
• Which expenditure types generate the highest revenue? <br>
• How does revenue change across quarters? <br>
• Which customer segments contribute the most income? <br>
• Which payment or usage channels are most frequently used? <br>
• How are customers distributed by gender, age, education, and profession? <br>
• How does customer satisfaction vary across different customer groups? <br>


<h2>🎯 Goal of the Dashboard </h2>

The primary goal of this project is to develop an interactive financial analytics solution that:

• Monitors overall credit card revenue and transaction performance. <br>
• Analyzes interest earned and annual fee contributions. <br>
• Compares financial performance across card categories. <br>
• Identifies revenue patterns across expenditure types and customer segments. <br>
• Tracks quarterly revenue and transaction-count trends. <br>
• Analyzes customer demographics and income distribution. <br>
• Supports interactive filtering and detailed financial reporting. <br>
• Presents complex financial data in a simple, user-friendly format. <br>
